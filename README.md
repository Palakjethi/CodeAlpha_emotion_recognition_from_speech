# Speech Emotion Recognition (SER)

CNN-LSTM based emotion recognition from speech using MFCC features.
Datasets: **RAVDESS**, **TESS**, **EMO-DB (Berlin)**.

## 1. Project Structure

```
ser_project/
├── data/
│   ├── raw/                # put downloaded datasets here (see below)
│   │   ├── RAVDESS/
│   │   ├── TESS/
│   │   └── EMODB/
│   └── labels.csv          # generated by build_dataset.py
├── utils/
│   ├── label_parser.py     # parses filenames -> unified emotion labels
│   └── features.py         # MFCC + delta + delta-delta extraction
├── models/
│   └── cnn_lstm.py         # CNN-BiLSTM model definition
├── build_dataset.py        # step 1: scan raw/ folders, build labels.csv
├── extract_features.py     # step 2: extract & cache MFCC features (.npy)
├── train.py                # step 3: train the model
├── predict.py               # step 4: run inference on a new .wav file
└── requirements.txt
```

## 2. Download the datasets (manual step — not automatable)

| Dataset | Link | Put files under |
|---|---|---|
| RAVDESS (Speech only, Audio-only zip) | https://zenodo.org/record/1188976 | `data/raw/RAVDESS/Actor_*/...wav` |
| TESS | https://tspace.library.utoronto.ca/handle/1807/24487 | `data/raw/TESS/*/...wav` |
| EMO-DB (Berlin) | http://emodb.bilderbar.info/download/ | `data/raw/EMODB/wav/*.wav` |

Unzip each dataset keeping their **original folder/filename structure** — the label
parser depends on the original filenames to extract emotion labels.

## 3. Setup

```bash
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## 4. Run the pipeline

```bash
python build_dataset.py         # -> data/labels.csv  (path, dataset, emotion, speaker)
python extract_features.py      # -> data/features.npz (X, y, speakers)
python train.py                 # trains CNN-BiLSTM, saves models/best_model.pt
python predict.py path/to/file.wav
```

## 5. Unified emotion label set

To combine all three datasets, labels are mapped to a common set of 7 classes:

```
neutral, happy, sad, angry, fear, disgust, surprise
```

`calm` (RAVDESS) is merged into `neutral`.
`boredom` (EMO-DB) is kept separate but excluded by default from the unified set
since it has no counterpart in the other datasets (configurable in `label_parser.py`).

## 6. Notes

- Train/val/test split is done **by speaker**, not by random sample, to properly
  test generalization to unseen voices (see `train.py`).
- EMO-DB is German while RAVDESS/TESS are English — this is a known limitation;
  you can filter to a single dataset in `build_dataset.py` if you want a
  single-language baseline first.
